# Purpose 
A place to share SKILL.md files or other prompts / detailed instructions consumable by humans and AIs to take the tedium 
out of standards work.   They SHOULD use only public information, so there should not be W3C member confidentiality concerns.  

Also a place to compare notes on the results or share the (generally verbose) LLM analyses of particular charters.  This lets us compare how different LLMs and human reviewers process the review instructions.
